# ARTIST INDEX — m3rzo

Тёмный адаптивный каталог музыкальных исполнителей в техно-эстетике портфолио m3rzo.

## Возможности

- Включены все 1766 уникальных артистов из `sologle/zvuka-v-ukho-artists` (локальный снимок каталога).
- Разделы: все (1766), популярные (297), СНГ (475), зарубежные (1291), избранное.
- Копирование имени в один клик по карточке. На HTTP и в `file://` предусмотрен fallback; для лучшей поддержки откройте через localhost или HTTPS.
- Поиск по именам, сортировка, подгрузка порциями, сохранение избранного в браузере.
- Адаптивная вёрстка для телефона и компьютера.
- Не требуется база данных, ключи API, регистрация или платный хостинг.

## Как запустить

**Без сборки:** откройте `index.html` в браузере. Файлы каталога уже включены.

**Локальный сервер:** из папки проекта выполните `python -m http.server 8000`, затем откройте `http://localhost:8000`.

**На Vercel:** загрузите папку проекта или GitHub-репозиторий. Framework preset: `Other`; Output Directory: пустое значение / корень проекта. Команда сборки не нужна — сайт статический. Если Vercel выполняет `npm run build`, этот скрипт попытается обновить список, а при недоступности GitHub сохранит локальную копию.

## Обновить исполнителей

`npm run sync` — загрузит данные из исходного репозитория и обновит `data/artists.json` и `artists-data.js`.

Исходник каталога: https://github.com/sologle/zvuka-v-ukho-artists (неофициальный независимый интерфейс). Авторские права на список и на торговые марки остаются у соответствующих правообладателей.
